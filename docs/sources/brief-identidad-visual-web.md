Imagen de referencia de producto: estuches cilíndricos de piel en paleta sobria. Esta imagen funciona como punto de partida de lenguaje visual, no como límite creativo.

Versión 1.0 · Documento maestro para diseño, desarrollo, producción visual y ecommerce

# 0. Propósito del documento

Este documento convierte la dirección creativa de Obsequiums en un brief técnico, operativo y entregable para el equipo que diseñe y desarrolle la nueva web. La intención es que dirección de arte, UX/UI, desarrollo, fotografía, video, contenido, ecommerce, CRM y performance trabajen desde una misma definición visual y funcional, sin tener que volver a preguntar qué debe transmitir la marca, cómo debe verse, cómo debe comportarse la web o qué assets hacen falta.

Obsequiums debe dejar de leerse como una simple watch box. Debe construirse como una marca de marroquinería de lujo accesible que diseña estuches de piel personalizables para relojes, pulseras, brazaletes, joyas de viaje y piezas personales con valor emocional. El ecommerce no será una tienda plana: será un espacio editorial, sensorial y confiable que haga sentir el producto antes de tocarlo.

Para las piezas que no se guardan en cualquier lugar.

## Entregables que este documento debe habilitar

- Diseño completo de ecommerce mobile-first con estética premium, editorial, sensorial y clara.
- Sistema visual coherente para home, producto, categorías, gifting, personalización, journal, CRM y campañas.
- Brief de producción fotográfica y audiovisual con encuadres, luz, ritmo, sonido, props, casting y usos.
- Guía de UX/UI con componentes, microinteracciones, animaciones, navegación y criterios de conversión.
- Especificación funcional para desarrolladores: estructura, plantillas, CMS, performance, tracking y QA.
- Lista de assets necesarios para lanzar la web y alimentar redes, paid media, Pinterest, email y PR.
- Criterios de aprobación para CEO/dirección general antes de salir a producción o publicación.

# 1. Norte creativo de marca

## 1.1. Idea rectora

La idea rectora visual de Obsequiums es la calma de cuidar lo que importa. Todo debe nacer desde ahí: luz, ritmo, copy, composición, interfaz, video, sonido, packaging, navegación y experiencia de compra. La marca no debe gritar lujo. Debe demostrar criterio. No debe explicar demasiado. Debe hacer sentir que el producto pertenece a una vida más cuidada.

## 1.2. Concepto visual

Concepto recomendado: Objects of Intimacy / La intimidad de lo que eliges guardar. Este concepto permite unir relojes, pulseras, brazaletes, joyas, regalos, viajes y objetos de etapa sin fragmentar el relato. La marca debe mostrar aquello que se lleva sobre la piel y luego se guarda con intención.

## 1.3. Frases rectoras para el sistema visual

- Un lugar digno para las piezas personales con valor emocional.
- La belleza silenciosa de guardar bien.
- El lujo accesible como ritual, no como ostentación.
- La personalización como gesto íntimo, no como decoración.
- La web como experiencia sensorial, no como catálogo.

# 4. Sistema cromático

## 4.1. Dirección general

La paleta debe ser cálida, neutra, desaturada, táctil y atemporal. El color acompaña al cuero y a la vida íntima del cliente; no compite con el producto. La web debe evitar blancos clínicos, negros excesivamente duros y colores saturados que rompan la sensación de lujo accesible y calma.

| Color | HEX sugerido | Uso recomendado |
| --- | --- | --- |
| Hueso / marfil cálido | #F4F0E8 | Fondos principales, bloques amplios, sensación de calma. |
| Arena | #D8CBBB | Fondos secundarios, separadores suaves, tarjetas editoriales. |
| Greige | #B8AEA0 | Fondos de producto, módulos de confianza, hover sutil. |
| Taupe | #8B7B6A | Texto secundario, líneas, etiquetas, captions. |
| Carbón suave | #2E2924 | Texto principal, botones oscuros, contraste premium. |
| Camel cuero | #B7794C | Acento vinculado al producto, CTAs secundarios, storytelling de piel. |
| Chocolate | #4A3328 | Profundidad, titulares, fondos de lujo silencioso. |
| Verde musgo | #596153 | Acento para colecciones verdes, escenas de viaje y naturaleza. |
| Azul humo | #637383 | Acento para producto azul, calma y precisión. |
| Latón suave | #A48658 | Detalles de personalización, iconos premium, acentos muy controlados. |

## 4.2. Reglas de uso cromático

- Usar fondos cálidos y ligeramente texturados en la home para evitar sensación de catálogo frío.
- Reservar el carbón para texto y CTAs de alto contraste; no usarlo como fondo dominante en toda la web.
- Usar los colores del producto como acentos editoriales, no como bloques saturados.
- Evitar gradients llamativos. Si hay degradados, deben ser casi imperceptibles, cálidos y atmosféricos.
- Mantener alto contraste en texto y botones para accesibilidad, especialmente en mobile.

# 5. Sistema tipográfico

## 5.1. Dirección tipográfica

La tipografía debe equilibrar alma y precisión. Una serif refinada debe aportar dimensión editorial, tiempo y sensibilidad. Una sans serif limpia debe aportar claridad ecommerce, legibilidad mobile y eficiencia funcional. La combinación debe decir: somos emocionales, pero comprarnos es simple.

| Nivel | Dirección | Uso |
| --- | --- | --- |
| Display / titulares | Serif refinada tipo editorial: Georgia, Cormorant Garamond, Canela-like, Freight-like o similar licenciable. | Hero, claims, titulares de secciones, mensajes emocionales. |
| Texto funcional | Sans serif limpia: Aptos, Inter, Neue Haas Grotesk-like, Söhne-like o similar licenciable. | Menús, fichas, precios, botones, FAQ, checkout, microcopy. |
| Detalles / captions | Sans serif en tamaño pequeño, tracking suave, color taupe. | Captions, etiquetas, notas de producto, tiempos de envío. |
| Números / datos | Sans serif clara con buena lectura de cifras. | Precios, medidas, unidades, fechas límite de gifting. |

## 5.2. Jerarquía recomendada en web

| Elemento | Especificación | Regla |
| --- | --- | --- |
| H1 hero desktop | 56-72 px, serif, line-height 0.95-1.05 | Frases cortas, nunca párrafos largos. |
| H1 hero mobile | 36-44 px, serif, line-height 1.05 | Debe entrar bien en 2-4 líneas. |
| H2 secciones | 32-44 px desktop / 28-34 mobile | Editorial, con mucho aire arriba y abajo. |
| Body | 16-18 px, sans, line-height 1.55-1.7 | Legible, claro, sin bloques densos. |
| Microcopy | 12-14 px, sans, line-height 1.35 | Envíos, personalización, avisos, FAQ. |
| CTA | 13-15 px, sans, semibold, tracking leve | Directo, nunca críptico. |

# 6. Sistema fotográfico

## 6.1. Principio general

La fotografía es el principal vendedor sensorial de Obsequiums. Debe compensar la imposibilidad de tocar el producto online. Cada imagen debe responder a una de estas funciones: hacer sentir el cuero, mostrar escala, demostrar uso real, explicar personalización, resolver confianza o construir deseo de regalo.

## 6.3. Parámetros técnicos de imagen

| Parámetro | Especificación |
| --- | --- |
| Exposición | Baja a media-baja, con producto siempre legible. La sombra debe dar intimidad, no ocultar información. |
| Luz | Lateral, natural filtrada o softbox muy difuso. Temperatura cálida-neutra. Evitar flash frontal. |
| Foco | Profundidad de campo corta para macros; foco total en producto para PDP técnico. |
| Composición | Aire, equilibrio, no saturar de props. El producto manda. |
| Color grading | Desaturado, cálido, contraste suave, negros no empastados. |
| Formato | Capturar en horizontal, vertical y cuadrado desde la misma escena para reutilizar. |
| Resolución | Mínimo 3000 px lado largo para web/PR; compresión optimizada para performance. |
| Recortes | 1:1, 4:5, 9:16, 16:9 y 3:2. Cada producción debe cubrir todos. |

## 6.4. Props aprobados y prohibidos

| Categoría | Elementos |
| --- | --- |
| Aprobados | Relojes, pulseras, brazaletes, anillos, perfume discreto, lino, seda, blazer, libreta, libro, café, pasaporte, llaves, maleta, piedra, madera, bandeja, tarjeta manuscrita, flor sutil. |

# 7. Sistema de video, motion y ASMR

## 7.1. Video como lenguaje principal

El video debe ser central porque el producto tiene gestos: abrir, cerrar, tocar, guardar, personalizar, regalar y viajar. El video debe transmitir calma, textura y precisión. Debe haber piezas editoriales lentas y piezas de performance más directas, pero ambas deben mantener la misma dignidad visual.

| Formato | Duración | Contenido | Uso |
| --- | --- | --- | --- |
| Macro sensorial | 5-12 s | Cuero, costura, cierre, iniciales, interior. | Home loops, reels, PDP, ads consideración. |
| Ritual de uso | 15-30 s | Persona guardando reloj o pulsera antes/después de salir. | Social, PDP, campaña marca. |
| Travel ritual | 15-30 s | Preparación de maleta, hotel, estuche viajando. | Travel campaign, Pinterest, TikTok. |
| Personalización | 10-20 s | Proceso de iniciales y resultado final. | PDP, paid conversión, stories. |
| Unboxing | 20-45 s | Packaging, papel, tarjeta, revelación, producto. | Gifting, UGC, postcompra. |
| UGC guiado | 15-45 s | Creator cuenta qué pieza guarda y por qué. | Social proof, ads, PDP reviews. |

## 7.2. ASMR: guía de sonido

El ASMR debe ser elegante, no caricaturesco. El sonido debe amplificar materialidad y calma. Debe capturarse en producción, no inventarse completamente en edición.

| Elemento | Especificación |
| --- | --- |
| Sonidos principales | Roce del cuero, cierre, apertura, reloj apoyándose, pulsera entrando, papel grueso, cinta, caja abriéndose, maleta cerrando. |
| Mezcla | Sonido cercano, limpio, sin saturación. Música opcional muy tenue. Momentos de silencio intencional. |
| No hacer | ASMR exagerado, artificial, sonidos demasiado altos, música viral incompatible, efectos de transición agresivos. |
| Uso web | Loops sin sonido por defecto; opción de video en PDP; sonido principalmente en redes y landing de campaña. |

## 7.3. Motion y animaciones web

| Animación | Especificación | Aplicación |
| --- | --- | --- |
| Fade in | 400-700 ms, ease-out suave. | Entrada de bloques, titulares y módulos editoriales. |
| Parallax sutil | Muy leve; no debe marear ni parecer plantilla. | Hero y storytelling si mejora inmersión. |
| Hover producto | Cambio suave de imagen: cerrado/abierto o color/detalle. | PLP, PDP thumbnails. |
| Microinteracción personalización | Vista previa de iniciales en tiempo real, transición limpia. | PDP y módulo de personalización. |
| Sticky CTA mobile | Aparece sin tapar contenido crítico. | PDP, carrito, gift guide. |
| Scroll narrativo | Secciones con ritmo editorial, no exceso de efectos. | Home, campaña, journal. |

# 10. Página de producto / PDP

## 10.1. Principio de PDP

La PDP debe resolver la pregunta emocional y racional de comprar un producto premium sin tocarlo. La persona debe entender: qué es, para qué sirve, cómo se siente, qué cabe dentro, cómo se personaliza, cómo llega, cómo se devuelve y por qué vale lo que cuesta.

| Módulo PDP | Contenido | Objetivo |
| --- | --- | --- |
| Galería inicial | 12-16 assets mínimos: cerrado, abierto, reloj, pulseras, macro, mano, escala, maleta, tocador, iniciales, packaging, video. | Hacer sentir y entender. |
| Nombre + promesa | Nombre del producto + frase emocional funcional. | Dar identidad. |
| Selector de color | Swatches reales con nombre elegante, foto al cambiar. | Facilitar elección. |
| Personalización | Campo iniciales, previsualización, coste/tiempo visible. | Aumentar pertenencia y AOV. |
| CTA sticky | Añadir al carrito / Personalizar el mío. | No perder intención en mobile. |
| Beneficios rápidos | Piel, interior protector, ideal viaje, regalo, personalizable. | Claridad en 5 segundos. |
| Descripción editorial | Párrafo emocional + párrafo funcional. | Conectar deseo y uso. |
| Medidas visuales | Fotos con mano, reloj, pulsera, maleta. | Resolver escala. |
| Usos | Para relojes, pulseras, viaje, tocador, regalo. | Ampliar mercado. |
| Materiales y cuidado | Detalles técnicos claros. | Justificar precio y reducir dudas. |
| FAQ contextual | Sirve para pulseras, cuántas piezas, entrega, personalización, devoluciones. | Reducir contacto y abandono. |
| Reviews / UGC | Fotos reales, testimonios breves, rating si aplica. | Confianza. |
| Cross-sell editorial | Gift guide, journal, productos relacionados. | Aumentar navegación. |

# 11. Personalización: UX y experiencia visual

La personalización debe ser un momento de deseo, no un formulario. El usuario debe sentir que está convirtiendo el producto en algo propio o en un regalo con intención.

| Elemento | Especificación |

| Vista previa | Mockup en tiempo real de iniciales sobre el producto o aproximación visual elegante. |

## 12.2. Packaging y unboxing en web

- Incluir una sección visible de packaging en PDP y Gift Guide, no solo en FAQ.

# 15. Requisitos mobile-first

La mayoría del tráfico vendrá desde redes y paid social; por lo tanto, mobile no es una adaptación, es el punto de partida. La web debe sentirse rápida, visual, táctil y clara en pantallas pequeñas.

- Hero mobile con video corto o imagen potente que no pese excesivamente.
- CTA visible sin invadir; sticky en PDP después de la primera sección.
- Galería mobile con swipe natural y thumbnails claros.
- Texto emocional breve; información técnica en accordions.
- Personalización usable con una sola mano: campo claro, preview y validación inmediata.
- Checkout con Apple Pay, Google Pay, PayPal u opciones rápidas si el stack lo permite.
- Carga prioritaria de imagen hero y primera imagen de producto; lazy load para el resto.
- No depender de hover en mobile; todas las funciones deben tener equivalente táctil.

# 17. Accesibilidad y performance

## 17.1. Accesibilidad

- Contraste suficiente entre texto y fondo, especialmente sobre imágenes de baja exposición.
- No usar texto pequeño en imágenes como única fuente de información.
- Todos los videos deben tener alternativa visual clara y no depender de sonido para entenderse.
- Alt text descriptivo en imágenes de producto, uso, personalización y packaging.
- Navegación por teclado en menús, accordions, swatches, formularios y checkout.
- Estados focus visibles, refinados y coherentes con marca.
- Formularios con labels reales, mensajes de error claros y validación accesible.
- Evitar animaciones que no respeten reduced motion.

## 17.2. Performance

| Métrica/área | Objetivo | Regla |
| --- | --- | --- |
| LCP | < 2,5 s en páginas clave. | Optimizar hero, usar imagen/video responsive y preload controlado. |
| INP | < 200 ms ideal. | Minimizar JS innecesario, componentes ligeros. |
| CLS | < 0,1. | Reservar espacio para imágenes, banners y sticky elements. |
| Imágenes | WebP/AVIF, srcset, lazy loading, compresión sin perder tactilidad. | No subir imágenes gigantes sin optimizar. |
| Video | Loops cortos, muted, poster image, carga diferida. | Evitar autoplay pesado en mobile si afecta carga. |
| Apps/plugins | Mínimos necesarios. | No destruir velocidad con apps de marketing superpuestas. |

# 23. Do / Don't creativo y técnico

| Área | Do | Don't |
| --- | --- | --- |
| Fotografía | Primeros planos, luz baja pero legible, textura, manos, vida real, composición con aire. | Foto plana de catálogo, blanco clínico dominante, props gratuitos, saturación. |
| Video | Ritmo lento, ASMR sutil, gestos reales, loops elegantes. | Transiciones agresivas, música viral incompatible, velocidad caótica. |
| Web | Editorial, modular, mobile-first, clara, rápida, emocional y confiable. | Plantilla genérica, banners agresivos, exceso de apps, checkout confuso. |
| Copy | Breve, sensorial y claro. | Frases vacías, lujo grandilocuente, poesía que oculta producto. |
| Personalización | Discreta, deseable, visible y fácil. | Formulario escondido, grabado visualmente tosco, falta de tiempos. |
| Gifting | Central en navegación y PDP. | Tratarlo como opción secundaria al final del checkout. |
| Marca | Lujo accesible, íntimo, transversal. | Marca masculina rígida o femenina decorativa. |

# 26. Resumen ejecutivo para el equipo

Obsequiums debe verse como una marca de lujo accesible, táctil, íntima y contemporánea. Su web debe hacer sentir el producto antes de tocarlo, explicar claramente que sirve para relojes, pulseras y piezas personales, y convertir la personalización y el gifting en motores centrales de deseo y conversión.

La dirección visual debe ser de baja exposición controlada, primeros planos, ASMR, textura, manos, personalización visible, escenas reales de viaje y vida íntima, paleta cálida desaturada, tipografía editorial precisa y UX extremadamente clara. El ecommerce debe ser editorial, pero no críptico; sensorial, pero rápido; aspiracional, pero comprensible; premium, pero cercano.

La web no debe vender una caja. Debe vender el gesto de guardar bien algo que importa.
